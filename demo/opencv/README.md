# opencv

## HSV

**HSV 是一种颜色空间（也叫 HSB）**，把颜色拆成【色相、饱和度、明度】，更贴近人眼感知；**OpenCV 做颜色识别、颜色直方图（就是刚才 calcHist 二维直方图）、颜色分割最常用**。

>
> RGB/BGR 是 “红绿蓝混合”，三个通道都混在一起，光照一变三个值一起乱；HSV 把**是什么颜色、艳不艳、亮不亮拆开**，抗光照干扰强很多。


1. **Hue（H，色相）：是什么颜色**
    - 本质是色环角度：标准理论 0～360°
    - ✅ **OpenCV 8UC1 图像压缩成 0～179**（为了塞进 0~255 的字节）
    - 参考：0≈红，60≈黄，120≈绿，180≈青，240≈蓝，300≈品红
    - 0 和 179 都是红色，色环首尾相接
2. **Saturation（S，饱和度）：颜色有多鲜艳**
    - OpenCV：**0～255**
    - S=0：无彩色，灰度 / 黑白；S 越大颜色越浓越鲜艳
3. **Value（V，明度 / 亮度）：明暗**
    - OpenCV：**0～255**
    - V=0：纯黑；V=255：该色相下最亮

>
> 一句话：H 管颜色种类，S 管浓淡，V 管亮暗

## YUV

一句话：**YUV = 亮度 (Y) + 两个色差 (U/V)，专门给视频、摄像头、编码用的色彩空间**，和 HSV 完全不是一类用途。

>
> 历史上 YUV 是模拟电视；**数字图像 / 摄像头里的 YUV 其实是 YCbCr**，大家口语统一叫 YUVMDN Web Do...

### 三个分量

- **Y（Luma 亮度）**：灰度信息，人眼对 Y 最敏感。只有 Y 就是黑白图。
  公式：\(Y=0.299R+0.587G+0.114B\)（BT.601）Microsoft ...
- **U（Cb，蓝色色差）**：蓝色和亮度的差值
- **V（Cr，红色色差）**：红色和亮度的差值

>
> 重点：U、V 描述的是**颜色偏移**，不是色相、饱和度！

### 色度采样（444 / 422 / 420，最核心）

人眼对亮度细节敏感、对颜色细节不敏感，所以 UV 可以降采样，**压缩体积，观感几乎不变**

- **4:4:4**：每个像素都有 Y、U、V，无压缩，画质最高
- **4:2:2**：每 2 个像素共用一组 UV，带宽减半一点（摄像机、HDMI）
- **4:2:0**：**最常用！** 2×2 一共 4 个像素，只存 1 组 UV。H.264/H.265、摄像头、NV12/NV21/I420 全是这个，数据量只有 RGB 一半

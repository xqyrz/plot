# OpenCV 常用色彩空间对照表

| 色彩空间 | 转换常量（BGR→XXX） | 通道含义（uint8 范围） | 核心特点 | 典型应用场景 |
| ---- | ---- | ---- | ---- | ---- |
| BGR / RGB | COLOR_BGR2RGB | B/G/R 或 R/G/B [0~255] | OpenCV 原生 BGR；RGB 是深度学习、UI 常用；亮度色度耦合 | 图像读写、显示、渲染 |
| BGRA / RGBA | COLOR_BGR2BGRA | B/G/R/A [0~255]，A = 透明度 | 增加 Alpha 透明通道 | PNG 透明图、图层混合 |
| GRAY（灰度） | COLOR_BGR2GRAY | Gray [0~255] | 单通道，人眼加权亮度 0.299R+0.587G+0.114B | 边缘检测、轮廓、模板匹配、阈值分割 |
| HSV | COLOR_BGR2HSV | H[0~179]，S[0~255]，V[0~255] | H 色相独立，适合颜色筛选；空间感知不均匀 | 颜色追踪、inRange 颜色抠取、调色 |
| HLS | COLOR_BGR2HLS | H[0~179]，L[0~255]，S[0~255] | L 为 Lightness 亮度，S 相对 L 计算饱和度 | 图像调色、光影滤镜 |
| YCrCb(YCC) | COLOR_BGR2YCrCb | Y[0~255]，Cr[0~255]，Cb[0~255] | Y 单独代表亮度，色度分离；JPEG 编码标准 | 肤色检测、摄像头图像、压缩编码 |
| CIE Lab | COLOR_BGR2Lab | L*[0~255]，a*[0~255]，b*[0~255] | 感知均匀色空间；欧氏距离近似人眼色差 | 工业色差检测、颜色聚类、光照鲁棒分割 |
| CIE Luv | COLOR_BGR2Luv | L*[0~255]，u*[0~255]，v*[0~255] | 感知均匀，偏向显示设备模型 | 显示器色差评估、图像检索颜色特征 |
| CIE XYZ | COLOR_BGR2XYZ | X/Y/Z [0~255] | CIE 基础标准空间，Lab/Luv 计算依赖它 | 色彩标定、色彩转换中间载体 |
| YUV | 多种（NV21/I420 等） | Y 亮度，U/V 色度（420 采样） | 色度降采样，节省带宽，硬件 ISP 常用 | 安卓相机、RTSP 视频流、原始码流 |

> 备注：
> 1. HSV 的 H 通道范围是 0~179，不是 0~360，是 OpenCV 对 uint8 的压缩；
> 2. Lab、Luv、HSV 等色彩空间直接 imshow 会显示异常，需要转回 BGR；
> 3. CMYK 印刷色彩空间，OpenCV cvtColor 无原生转换支持。




### HSV

**HSV 是一种颜色空间（也叫 HSB）**，把颜色拆成【色相、饱和度、明度】，更贴近人眼感知；**OpenCV 做颜色识别、颜色直方图（就是刚才 calcHist 二维直方图）、颜色分割最常用**。

>
> RGB/BGR 是 “红绿蓝混合”，三个通道都混在一起，光照一变三个值一起乱；HSV 把**是什么颜色、艳不艳、亮不亮拆开**，抗光照干扰强很多。


1. **Hue（H，色相）：是什么颜色**
    - 本质是色环角度：标准理论 0～360°
    - ✅ **OpenCV 8UC1 图像压缩成 0～179**（为了塞进 0~255 的字节）
    - 参考：0≈红，60≈黄，120≈绿，180≈青，240≈蓝，300≈品红
    - 0 和 179 都是红色，色环首尾相接
2. **Saturation（S，饱和度）：颜色有多鲜艳**
    - OpenCV：**0～255**
    - S=0：无彩色，灰度 / 黑白；S 越大颜色越浓越鲜艳
3. **Value（V，明度 / 亮度）：明暗**
    - OpenCV：**0～255**
    - V=0：纯黑；V=255：该色相下最亮

>
> 一句话：H 管颜色种类，S 管浓淡，V 管亮暗

### YUV

一句话：**YUV = 亮度 (Y) + 两个色差 (U/V)，专门给视频、摄像头、编码用的色彩空间**，和 HSV 完全不是一类用途。

>
> 历史上 YUV 是模拟电视；**数字图像 / 摄像头里的 YUV 其实是 YCbCr**，大家口语统一叫 YUVMDN Web Do...

#### 三个分量

- **Y（Luma 亮度）**：灰度信息，人眼对 Y 最敏感。只有 Y 就是黑白图。
  公式：\(Y=0.299R+0.587G+0.114B\)（BT.601）Microsoft ...
- **U（Cb，蓝色色差）**：蓝色和亮度的差值
- **V（Cr，红色色差）**：红色和亮度的差值

>
> 重点：U、V 描述的是**颜色偏移**，不是色相、饱和度！

#### 色度采样（444 / 422 / 420，最核心）

人眼对亮度细节敏感、对颜色细节不敏感，所以 UV 可以降采样，**压缩体积，观感几乎不变**

- **4:4:4**：每个像素都有 Y、U、V，无压缩，画质最高
- **4:2:2**：每 2 个像素共用一组 UV，带宽减半一点（摄像机、HDMI）
- **4:2:0**：**最常用！** 2×2 一共 4 个像素，只存 1 组 UV。H.264/H.265、摄像头、NV12/NV21/I420 全是这个，数据量只有 RGB 一半
